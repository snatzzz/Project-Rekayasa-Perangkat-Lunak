# Smart Motorcycle Health & Maintenance System

Silakan lihat dokumentasi lengkap sistem, arsitektur, panduan Docker, Prisma migration, API, dan petunjuk presentasi pada file [README.md utama di root direktori project](../../README.md).

### Quick Start:

1. **Jalankan Database**:
   ```bash
   docker compose up -d
   ```

2. **Jalankan Backend (Port 3000)**:
   ```bash
   cd apps/api
   npm run dev
   ```

3. **Jalankan Frontend (Port 5173)**:
   ```bash
   cd apps/web
   npm run dev
   ```
