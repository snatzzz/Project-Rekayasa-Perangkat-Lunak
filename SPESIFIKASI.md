## Spesifikasi Sistem

### 1. Platform
- Aplikasi berbasis web.
- Digunakan oleh pemilik kendaraan bermotor untuk memantau kondisi dan perawatan motor.
- Tidak menggunakan sistem login pada versi awal.

### 2. Frontend
- React
- TypeScript
- Vite
- Tailwind CSS

### 3. Backend
- Node.js
- TypeScript
- Express.js
- REST API

### 4. Database
- MySQL
- Prisma ORM
- Docker Compose untuk menjalankan MySQL

### 5. Fitur Utama
- Menambahkan dan mengelola profil motor.
- Mencatat kilometer kendaraan.
- Mencatat riwayat servis dan perawatan.
- Memberikan rekomendasi jadwal perawatan berdasarkan kilometer dan riwayat servis.
- Reminder untuk perawatan yang sudah mendekati jadwal.
- Menampilkan Motorcycle Health Score.
- Memberikan rekomendasi awal berdasarkan keluhan pengguna.

### 6. Data yang Dikelola
- Data kendaraan.
- Kilometer kendaraan.
- Riwayat servis.
- Jenis perawatan.
- Tanggal perawatan.
- Biaya perawatan.
- Keluhan atau gejala kendaraan.

### 7. Kebutuhan Perangkat Lunak
- Windows / macOS / Linux
- Node.js
- npm
- Docker Desktop
- Git
- Visual Studio Code
- Browser (Chrome/Edge)

### 8. Kebutuhan Perangkat Keras
- RAM minimal 8 GB
- Processor minimal Intel Core i3 / AMD Ryzen 3
- Penyimpanan minimal 5 GB
- Koneksi internet
